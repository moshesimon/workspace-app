# Implementation module contracts
All TypeScript imports use relative paths and `.js` suffixes. No aliases. Main controller owns SQLite and operations; leaf modules return serializable data. Use DomainError(code,message,details?) from packages/contracts/src/errors.ts.

Manifest shape (packages/contracts/src/project-configuration.ts): schemaVersion:1, name:string, repositories: Array<{key,path,sourceRef?:string}>, prerequisites:Array<{id,executable,args?:string[]}>, setup:Array<{id,repository,executable,args:string[],cwd:string,env:Record<string,string>,dependsOn:string[],runPolicy:'oncePerInputs'|'always',probe?:{executable,args:string[]}}>, services:Array<{id,repository,executable,args:string[],cwd:string,env:Record<string,string>,dependsOn:string[],runtimePaths:string[],port?:{preferred:number,min:number,max:number},readiness?:{type:'http'|'tcp'|'process',path?:string,timeoutMs?:number},url?:string}>, resources:Array<{id,repository,adapter:'process'|'command'|'external',executable?:string,args:string[],cwd:string,env:Record<string,string>,dependsOn:string[],port?:{preferred,min,max},hooks?:{start:Command,status:Command,stop:Command,destroy:Command},disposablePaths:string[],url?:string}>, bindings:Record<string,string>,entrypoints:Array<{label,service:string}>. Command={executable,args:string[]}. Defaults empty arrays/maps,cwd='.', args=[]. Tokens workspace.id,checkout.path,self.port,self.url,service.<id>.url,service.<repo>/<id>.url,resource.<id>.url,secret.<NAME>.

Entity Store (packages/controller/src/store.ts): get<T>(table,id):T|undefined; all<T>(table):T[]; put(table, entity:{id:string,...}):void; delete(table,id):void. Entities use id stable UUID plus JSON body persisted per-table. Controller gives Store to runtime.

Checkout: {id,workspaceId,repositoryId,repositoryKey,path,ownership:'created'|'adopted'|'discovered',createdBranch:string|null,currentBranch:string|null,sourceRef:string|null,sourceCommit:string|null,originEvidence:'recorded'|'unknown'|'user-declared',createdAt:string|null,registeredAt:string}. Repository: {id,projectId,key,path,commonDir,mainPath}. Workspace: {id,projectId,name,configurationRevisionId,createdAt,state,removedAt?:string}. Project: {id,name,root,configurationRevisionId,createdAt}. Revision {id,projectId,manifest,hash,createdAt}. Operation {id,idempotencyKey,action,status:'queued'|'running'|'succeeded'|'partial'|'failed',createdAt,updatedAt,result?:unknown,error?:{code,message},outcomes:unknown[]}.

Shared renderer API window.worktree: call(name:string,input?:Record<string,unknown>):Promise<any>; chooseFolder():Promise<string|null>; openExternal(url:string):Promise<void>. Mutations return Operation; UI must poll operations.get ({operationId}) until settled then use operation.result. Inputs include idempotencyKey crypto.randomUUID(). Query arrays returned as arrays except workspaces.get returns {workspace,checkouts,services,resources,setup,project,configuration}. Workspaces list returns enriched array { ...workspace,checkouts,services,projectName }. projects.get returns {project,repositories,configuration}; configuration.get returns revision. Projects register {root,name?,manifest?}; workspaces.create {projectId,name,branch?,sourceRef?} creates worktrees for all configured repositories under private data root. checkouts.get {checkoutId} returns Checkout. Changes list {checkoutId} => {files:Array<{path,originalPath?,indexStatus,worktreeStatus,staged,unstaged,untracked}>,staged,unstaged,untracked,clean}; diff {checkoutId,path,area:'staged'|'unstaged'|'untracked'} => {text,binary,truncated}. history.list {checkoutId,limit?,offset?} => {commits,commitsSinceBase}; commits {hash,subject,author,date}. history.commit {checkoutId,commit} => {text}. lifecycle.* {workspaceId,checkoutId?}; setup.run same. logs {serviceId|receiptId,offset?,limit?} => {text,nextOffset}. destroy.preview {workspaceId,checkoutId?} => {id,expiresAt,targets:[{checkoutId,path,branch,files,dirty}],warnings,retainedBranches}; execute {previewId,discardChanges:boolean,idempotencyKey}. operations.get {operationId}.
